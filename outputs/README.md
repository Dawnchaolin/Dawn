# 墨战 · 键影 —— 打字闯关

一款纯静态的单页打字闯关游戏，水墨风视觉。二十二境递进（含第 15、16 两境 Boss 攻防关、第 17–19 三境短句长文关与第 20–22 三境整篇长文关），过关需在限时内斩满目标；精准度不计入门槛，只进入战报与无瑕判定。主线之外另有三种独立玩法：**大破外军**（高中英语 3500 词，按词频编阵）、**无限模式**（自选英语 / 长句 / 文章随机连战）与**自定义词战**（自建词库并按编号编排关卡）。另有 **Windows 桌面版**：内嵌房间服务，局域网自动发现房间，可双人同题对战；单机玩法在桌面版与浏览器 `file://` 下完全一致。无需构建、无需联网；立绘为本地 PNG 素材，音效为本地程序化合成，全部随目录离线加载，不发起网络请求。

## 运行

- 单机 · 双击 `index.html` 即可（脚本按普通 `<script defer>` 顺序加载，兼容 `file://`）。
- 单机 · 也可在本目录起静态服务后访问，例如 `python -m http.server 8777`。
- 桌面版 · 双击 `release/MozhanKeyblade-win32-x64/MozhanKeyblade.exe`。应用启动时会自行拉起内嵌房间服务并打开界面，无需手动起服务或输入地址。
- 联机 · 需使用桌面版（`file://` 页面之间无法建立 WebSocket 连接）；同一局域网内一人开房、一人加入即可。
- 首次点击页面任意处会解锁 Web Audio（浏览器策略），此后击键音与击键同一帧触发。
- 推荐使用桌面浏览器，窗口宽度 1180px 以上以获得最佳构图；窄屏会等比缩放并按列堆叠。

## 操作

| 操作 | 效果 |
| --- | --- |
| 输入正确字母 | 对最近敌人发射一次普通攻击（100% 攻击力 × 精准加成） |
| 完成单词 / 全部拼音后按空格 | 重击（300% 攻击力 × 精准加成 × 长词倍率） |
| 正确输入累计 30 次后按 Enter | 释放终极一击（未蓄满时只提示进度，不触发） |
| 速字模式下正确上屏整词 | 自动发出重击，无需再按空格 |
| 斩满目标 + 限时内完成 | 过关；超时或生命归零即判负，精准度不再作为门槛 |
| Tab | 切换当前词帖 |
| 点击词帖 | 切换当前词帖 |
| Esc | 暂停 / 继续 |
| `音` 按钮 | 静音开关 |

攻击自动锁定离玩家最近的敌人。投射物从角色手部实际飞出并飞行到目标后才结算伤害，不在目标点直接命中。

## 数值口径

- 基础攻击力 `ATK = 12`，玩家生命 `100`。
- **精准度** = 正确字母数 ÷ 总输入字母数 × 100%，四舍五入显示；本局尚未输入时按 100% 计。
- **伤害加成** `= 1 + 精准度 ÷ 100`。即精准度每高 1 个百分点，伤害 +1%。
- **普通攻击** `= round(ATK × 伤害加成)`。精准 100% 时 24 点，精准 50% 时 18 点。
- **重击** `= round(ATK × 3 × 伤害加成 × 长词倍率)`。精准 100%、无长词加成时 72 点。
- 长词倍率只在重击与速字直击时生效，普通逐字母攻击不享受（见下节）。
- **速字直击**（速字模式下整词自动发射）额外附带凝聚伤害：`+ round(ATK × 伤害加成 × 该词字母数)`，即把取消掉的逐字母普通攻击折算进这一击，避免中文整词玩法因少打字母而输出不足。
- **终极一击**：正确输入累计 30 次解锁，伤害 = `round(ATK × 武器系数 × 伤害加成)`；弓为每支 0.75（每敌 6 支），剑 5，法杖 4.5，墨笔每趟 2.0（往返两趟各结算一次，末端墨爆再结算 2.0）。
- 伤害在发射瞬间锁定，飞行命中时结算；打错字母不会造成伤害，但会降低后续所有攻击的精准加成。
- 怪物进入底部“领地”线：玩家扣除该怪物的突破伤害，怪物自动消散（不计入斩杀数）。
- 每关有独立的目标斩杀数、怪物血量、移动速度、刷新间隔、同屏上限、词帖数量与限时。

### 过关判定

一境过关只需满足：

1. **斩满目标数**；
2. **在本境限时内完成**。

精度只影响伤害倍率与战报，不再是通关条件：

- 斩满目标即破境，不会因为精准不足判负；生命归零或超时才会失败。
- 结算页固定展示**本局最高精准度**（本局输入开始后累计精准度的最高值）、斩敌数、最高连击与用时。
- **零失误通关**（本局 `errors === 0`，全程没有一次错误输入）会在结算页额外盖一枚「无瑕」朱印；该标记会写入本境记录，关卡卡面显示「无瑕 · 最高精准」。
- HUD 常驻显示当前精准、剩余时间与连击；精准只作参考，不再转红。
- 暂停不计入限时；最佳记录按最高精准度保存。

## 难度设计

本作不靠单纯堆血量制造难度，而是组合六个可感知的变量，形成可预期的阶梯：

| 变量 | 作用方式 |
| --- | --- |
| 推进速度 | 敌人每秒下移的像素数，越高留给玩家的反应窗口越短 |
| 刷新间隔 | 新敌出现的间隔，越低越容易形成同屏压力 |
| 同屏上限 | 同时存在的敌人数量，超过上限时停止刷新，逼迫玩家先清场 |
| 词长与词库 | 从基准键位短词逐境过渡到长词、短语、大写、标点、成语 |
| 同屏与刷新 | 同屏上限由 6 逐境升到 11，刷新间隔由 1.05 秒压到 0.60 秒，压迫来自持续怪潮而非单体血厚 |
| 词帖数量与翻换 | 后期只剩 2 张词帖，并每 11–16 秒翻换一张未被你动过的词帖，压缩挑选空间 |
| 限时门槛 | 斩满目标后仍须在限时内完成，慢速逐键无法无限拖长 |

数值按“所需持续输出 ≈ 怪物平均血量 ÷ 刷新间隔”估算：低境约需每秒 1–2 个正确字母即可稳住，高境需要约每秒 4–5 个正确字母并配合重击。刷新间隔与同屏上限按词长配对校准：中文双字关刷新 1.15 秒、成语关 2.6 秒，避免长词打不完却被怪潮瞬间淹没。所有随机项只影响刷新间隔的 ±15% 与敌人种类配比，不改变门槛本身，避免纯随机挫败。

### 平衡基准（引擎模拟自测）

用引擎级模拟（逐帧推进战斗、按固定输入速率与正确率喂键）核定三档预期：

| 玩家档位 | 输入速率 / 正确率 | 预期结果 |
| --- | --- | --- |
| 熟练 | 4.2 字/秒 · 97% | 14 境全通；成语关约 75 秒、终局约 32 秒，中后段需控血 |
| 普通 | 2.6 字/秒 · 93% | 第 1–8 境可过，第 9 境起在同屏怪潮下掉血失败 |
| 新手 | 1.6 字/秒 · 88% | 第 1–6 境勉强可过且开始掉血，第 7 境起失败 |

也就是说：未练过的人不会“随便过”，失败几乎都来自同屏堆积与推进压力，而不是随机刷怪。精准度改为战报项后，通关仍会显示最高精准度；零失误者另得「无瑕」印。

## 长组合伤害倍率

倍率按词条的**字母数**计算：英文取整词字符数（含连字符），中文取全部拼音字母数（不含空格）。倍率乘在重击与速字直击上，逐字母普通攻击固定 ×1.0。

| 字母 / 拼音字母总数 | 倍率 | 典型词例 |
| --- | --- | --- |
| ≤ 4 | ×1.0 | moke（墨客）、muse（暮色） |
| 5 – 7 | ×1.1 | shanhe（山河）、jianghu（江湖）、lantern（灯笼） |
| 8 – 11 | ×1.25 | qingfeng（清风）、xingchen（星辰）、mountain（山岳） |
| 12 – 16 | ×1.45 | extraordinary（非凡）、yimingjingren（一鸣惊人） |
| ≥ 17 | ×1.7 | still-waters-deep（静水流深）、moon-over-the-pass（关山月） |

- 词帖左上角会显示当前倍率（如「长词 ×1.45」）；速字框头部同步显示。
- 重击命中时，玩家附近会浮出 `×倍率` 标记，便于确认长词收益。
- 风险回报：长词需要更长的连续正确输入，一旦失误会拉低精准度；打对则换来更高单次爆发。

## 英文释义

- 仅英文词在**重击发射后**触发（速字模式下的英文词同样适用）；汉字与逐字母普通攻击不触发。
- 释义取自词库内置的 `EN_MEANINGS`（最常用汉语义项），在词帖原位生成一张小笺。
- 展示总时长 **1.9 秒**：前 **1.05 秒**完整清晰；随后 **0.85 秒**向上轻扬、透明度线性衰减至 0，同时散出 14 粒淡墨，随墨迹自然消散，不会长期滞留。
- 数字、符号等无对应义项的词条不显示释义笺。

## 速字模式

主页菜单下方提供「速字模式」开关，状态写入 `localStorage`（`mozhan.save.v1` 的 `speedMode`），下次打开自动恢复。

- **开启后**：汉字词不再逐字母发射攻击。逐字母输入只累计精准度与连击，屏幕下方（玩家脚下）出现速字框，显示目标词、拼音进度与当前输入草稿。
- **输入法判定**：可逐字选字，也可一次上屏整个词；每次上屏都会按目标顺序校验汉字，已正确的部分会保留。双字词和四字成语只有全部汉字正确后才自动发出一次重击（含精准加成与长词倍率），无需再按空格。选错候选字不会推进，并回退到该字的拼音起点，可直接重输。
- **无输入法兜底**：直接用英文键位敲拼音且未使用输入法时，完整拼音正确即自动发射，保证无中文输入法环境也能游玩。
- 词帖打完后立即补新词并切换焦点。
- **手动重击**：速字模式下对汉字按空格会被提示「速字模式 · 打完整词自动发出」，避免误触；Enter 只服务于终极一击，不参与重击。
- **英文词**：在速字模式下仍保持普通玩法（逐字母攻击 + 空格重击），因此混战关会自然形成“中文整词爆发、英文逐字母推进”的双节奏。
- **打错**：与普通模式一致，断连击并落墨晕；拼音可删除回退后继续。
- 速字框中的 `×倍率` 为该词长词倍率；完成瞬间会浮出「速」字印与 `×倍率` 标记。

## 连击分档

连击只影响视听表现，不额外改变数值。打错一个字母立即断连击并落下轻微墨晕。

| 档位 | 触发连击 | 表现 |
| --- | --- | --- |
| 一重 | 0 | 基础墨点、基础音色；音高 0–1.9 半音 |
| 二重 | 10 | 墨点增多、轻微震屏；音高 2–3.9 半音，开始铺稳定调式 |
| 三重 | 25 | 朱红气韵、震屏加强；音高 4–5.9 半音，调式根音升 5 半音 |
| 四重 | 50 | 屏幕上下缘泛红、投射物拖尾更密；音高 7–8.9 半音，调式根音升 7 半音 |
| 五重 | 80 | 金红气场、最强震屏与粒子；音高 9–10.9 半音 |

- 击键音高按连击连续爬升：`组合音级 = comboSteps(combo)`，每 10 / 15 / 25 / 30 / 20 连击跨一个音级区间，区间内线性推进 0–1.9 个半音，跨档时落到下一个音级，不会回到低音。
- 连击到二重（≥10）后，整体音景进入 A 调稳定调式：低通滤波的 110Hz 根音 + 纯五度 + 三角波八度，二重根音 +0、三重 +5、四重及五重 +7 半音；断连击或停战时淡出，约 1.5 秒后停止振荡器。
- 每个正确字符都会在命中点落墨点或刀光，并叠一层墨渍到底层宣纸（缓慢淡出）；音效在 keydown / compositionupdate 的同一帧调用，无延迟。

## 键位分组熟练度

按键位把键盘分为五组：左手基准（`a s d f g`）、右手基准（`h j k l ; '`）、上排（`q … ] \`）、下排（`z … /`）、数字符号（数字与 Shift 符号）。每组按「期望键」累计准确率与击键速度（相邻同组击键间隔的 EMA，单位：键/秒），跨局写入 `mozhan.save.v1` 的 `prof`。

- 攻击倍率 `profMul = clamp(0.58 + accT × 0.42 + spdT × 0.20, 0.58, 1.22)`；
  - `accT = clamp((组准确率 − 60%) ÷ 38%, 0, 1)`，`spdT = clamp(组速度 ÷ 6.5, 0, 1)`；
  - 样本不足 8 次不惩罚，按 ×1.00 计；
  - 实测：准确 62% / 1.5 键/秒 → ×0.65；准确 99% / 7 键/秒 → ×1.20。
- 词的主键组取字母出现次数最多者（并列取靠后一组）；逐字母攻击、重击与速字直击都乘以该倍率。
- 招式表现：投射物尺寸 `×(0.34 + 倍率 × 0.68)`（约 0.68–1.18）；法杖雷击的预警环与天光柱同比例缩放，落雷延迟 0.18–0.40 秒（倍率越低越慢）。
- HUD 左上五条熟练度条：聚焦词所在组高亮，弱组转朱红；悬停可看准确率、速度与攻击倍率。

## 训练目标、破绽图与处方

- 每局开场随机给出一个训练目标：
  - 某根手指误击 ≤ N 次（`N = round(本境斩敌目标 ÷ 7)`，限 1–5）；
  - 本境最终精准 ≥ X%（有记录取上次最高精准 +1，否则 93 / 91 / 89 随关卡，限 84–99）；
  - 某弱键组准确率 ≥ X%（跨局该组准确率 +4，限 82–98，需本局至少 6 次样本）。
  - 历史误击 ≥ 8 次的手指目标权重更高（3 倍）。
- 达成目标且破境，得稀有奖励「墨玉」一枚（`save.jade`）；开场与结算都会显示。
- 结算「破绽图」：本局错得最多的前三键、拖后腿的手指、四排键位热力图（1 次浅朱、≥3 次深朱），并列出五组跨局熟练度（准确率 / 速度 / 攻击倍率）。
- 破绽转处方：取本局最易错的三个字母写入 `save.prescription`，下一局约 50% 的词帖从含这些字母的词中抽取；无字母破绽时取本局最弱键组。

## 中文输入方案

中文词帖同时显示汉字与拼音。输入路径如下：

1. 使用系统拼音输入法，隐藏输入框接收 `compositionstart / compositionupdate / compositionend`。
2. `compositionupdate` 每产生一个拼音字母，就与当前词帖的拼音串逐字母比对：正确则立即计一次普通攻击并落墨，错误则断连击；删除拼音会同步回退已计入的字母。
3. `compositionend` 校验上屏汉字：所有组成字都正确上屏后，词帖才进入“重击就绪”，可按空格发射重击。只打对拼音但未选字上屏时不会就绪。
4. 若未检测到输入法事件（例如直接用英文键位敲拼音），所有拼音字母输入完成 0.5 秒后允许重击，保证无输入法环境也能通关。
5. 输入法选字常用 Enter / 空格：合成期间（`isComposing` / `keyCode 229` / `imeActive`）所有键位先被拦截，Enter 不会误触终极；上屏后的 220ms 内屏蔽重击，避免选字键误触；如需重击，松开后再次按下空格即可。
6. 词帖下方会实时显示当前拼音草稿，便于确认判定进度。
7. **速字模式**下上述第 2 步的“逐字母普通攻击”被取消，改为只累计精准度与连击；使用输入法时，以 `compositionend` 实际上屏的汉字逐字判定，整词全部正确才自动重击。未使用输入法时仍按完整拼音自动重击。

## Boss 攻防关（第 15、16 境）

- 第 15 境「镇关·名言」：10 句常用名言 / 古诗文（8–14 字，难度 1–3），守将 900 生命，限时 95 秒。
- 第 16 境「文心·终章」：10 句先秦诸子、史传与古文名篇（10–18 字，难度 3–5），守将 1600 生命，限时 150 秒。
- 每句都标注出处与难度；整句打完后自动循环下一句，不重复同一句。
- 版面：整句面板宽 `min(0.68W, 880)`、高 `clamp(0.20H, 144, 168)`，中心在 `(W/2, 0.385H)`；守将立于 `(W/2, 0.165H)`，半径 `clamp(0.076H, 46, 66)`，随轮次最多下压 10% 间距并每 3.2 秒前扑 18px。本源沿面板右侧的虚线路径推进，独立于面板绘制，互不遮挡。
- **一字一击**：每打完一个汉字的完整拼音，自动向守将发一矢普通攻击，伤害 `round(守将最大生命 × 0.011 × (0.9 + 精准度/1000) × (0.82 + 键组熟练倍率 × 0.18))`；900 生命约 9–11 点/字，1600 生命约 17–19 点/字。
- **标点必须输入**：按对应键位实际击键，不再自动跳过。`，`→ `,`（逗号键）、`、`→ `,`、`。`→ `.`（句点键）、`；`→ `;`、`：`→ `:`、`！`→ `!`（Shift+1）、`？`→ `?`（Shift+/）。输入法直接上屏的全角标点同样判定为对应键。打错计一次失误、断连击，进度不推进。
- **弹幕与拦截**：守将按间隔放出墨弹，第 15 境 2.6 秒起、最快 1.8 秒；第 16 境 2.0 秒起、最快 1.5 秒，飞行速度 132 / 150 px·s⁻¹。第 15 境第 19 轮起双发；第 16 境第 13 轮起双发、第 21 轮起三发。每完成一个汉字，普通攻击抵消**最近的一发**墨弹（浮出「挡」字），一发一字、不连带；双发/三发弹幕需在同一波内连续出字才能全拦。未被拦截的墨弹抵达城墙，造成 4（15 境）/ 5（16 境）点伤害。终结技的墨爆会扫清场上所有墨弹。
- **本源逼近**：守将每完成 4 轮攻击，其「本源」沿右侧虚线向城墙推进一阶（共 6 阶），面板脚注实时显示 `本源 n / 6`。推进到第 6 阶即「本源入城，城墙失守」，直接判负；每完成一整句终结技会把本源击退一阶。
- **终结技**：整句（含标点）打完后自动释放，无需按空格；终极一击独立计算，蓄满 30 次后仍可按 Enter 释放。`share = clamp(0.12 + 拼音字母数 / 1500, 0.14, 0.22)`，`伤害 = round(守将最大生命 × share × (0.9 + 精准度/1000) × (0.82 + 键组熟练倍率 × 0.18))`；同时回复至多 8 点生命（不超过 100）。900 生命单句终结技约 126–140，1600 生命约 224–350。
- 表现：逐字普通攻击为小号墨矢；终结技使用放大 1.45 倍的墨爆投射物、0.72 闪白、16 强度震屏，浮出「终」字，并清除本源一阶。
- 输入法：逐字母推进面板进度；标点可直按对应键，也可由输入法上屏全角标点（`，。；：？！`）后判定。

## 短句长文模式（第 17–19 境）

第 17–19 境不再散放词帖，而是把整段文字铺在城楼两侧的纸卷上，考验连续输入与断句节奏。

- **双侧版面**：左右各一卷，宽 `clamp(0.25W, 200, 350)`，内外缘距中轴 `0.06W`，顶端 `0.155H`；高度随本批行数在 `0.17H–0.40H` 之间自动收缩。中央留白，人物与城楼完整露出。
- **分批换卷**：一屏只显示当前批次，每批句数上限 `1 + ceil(难度/2)`，字数上限依次为 36 / 46 / 56 / 66 / 78（难度 1–5）。输完当前批次最后一个字母后 0.6 秒自动刷新下一批；一篇写尽自动换下一篇，队列耗尽后重新洗牌。
- **重击规则（自动释放，无需输出键）**：
  - 汉语以 2 个汉字为 1 词，遇逗号、顿号、分号、冒号也收词；每个词末自动释放一次重击（伤害 `ATK × 3 × 精准倍率 × 长词倍率 × 键组熟练倍率`）。
  - 句号、问号、叹号为句末：该词释放超级重击，伤害为词重击的 2.1 倍，并对同屏其余敌人各造成 0.7 倍溅射；附带 0.62 闪白、16 强度震屏与「终」字。
  - 英文按单词计词（撇号不切词），每个单词一次重击；句末单词触发超级重击。
  - 标点只显示、不参与输入；逐字母只累计精准、连击与键组熟练度。
- **输入方式**：中文可用输入法逐字上屏（拼音增量推进，同一段拼音内退格可回退），也可直接敲拼音字母；英文逐字母输入，大小写不敏感。
- **内容库**（`assets/longtexts.js`，127 篇，全部公版）：先秦诸子（道德经、论语、孟子、庄子、荀子、墨子、韩非子）、史传（左传、战国策、史记、汉书）、唐诗 20、宋词 15、古文名篇 16（岳阳楼记、滕王阁序、出师表、兰亭集序、陋室铭、爱莲说等）、日常寒暄 16、英文公版 12（莎士比亚、狄更斯、奥斯汀、华兹华斯、梭罗等）。
- **难度分级**：每篇标注 `lv 1–5`，6–92 字；lv1 19 篇（6–13 字）、lv2 44 篇（8–30 字）、lv3 53 篇（12–57 字）、lv4 7 篇（16–80 字）、lv5 4 篇（20–92 字）。第 17 境取 lv1–2，第 18 境取 lv2–3，第 19 境取 lv4–5（只余长句名篇与英文原文）。
- **底部词条**：`#long-strip` 实时显示当前出处、批次、当前词与拼音（已打字母转朱红），与两侧纸卷同步。

## 整篇长文模式（第 20–22 境）

与第 17–19 境的短句分批并列，主页新增独立的「整篇长文」入口。核心是**整篇文章的大块连续阅读**：不再逐句跳到别处，而是在两块纸块里顺着读、顺着打。

- **文章体量随关卡递增**：第 20 境取 lv1–2（81–276 字）、第 21 境取 lv3（320–448 字）、第 22 境取 lv4–5（456–749 字），全部为连续整篇的短文、散文与古文，不是单句轮换。
- **左下 / 右下双侧版面**：两块纸块分别锚定在城楼两侧（屏幕左下与右下），宽 `clamp(0.30W, 260, 480)`、高 `clamp(0.34H, 196, 320)`、顶端 `0.455H`；字号 `clamp(round(W/86), 14, 17)px`、行高 1.5。1440×900 下每块 9 行、1024×640 下每块 7 行；中央留白，人物与城楼不被遮挡，纸块底部贴近墙顶但不压人物。
- **整块翻页**：一篇先按左右两栏均衡铺满（`maxLines × 2` 行，左栏优先），读到本页最后一个字母后 0.6 秒，左右两块**同时整块换成下一页**，不做逐句跳转；末页读完后自动换下一篇，队列耗尽重新洗牌。翻页时浮出「整块翻页 · 第 n / m 页」。
- **阅读流**：当前词的每个字带浅朱底纹，当前字朱红加下划线；已打过的字淡化至 0.28 不透明度，未打为 0.88；当前词的汉字与拼音以小笺形式画在**本块右下角**，视线不必在中心与底部之间来回转移。原底部词条（`#long-strip`）在整篇模式自动隐藏。
- **输入规则沿用第 17–19 境**：汉语每 2 字成词（遇逗号、顿号、分号、冒号收词），词末自动重击；句号 / 问号 / 叹号为句末，触发 2.1 倍超级重击并对其余敌人溅射；标点只显示、不参与输入；无需空格；终极一击仍按 Enter 释放。
- **内容库**：`assets/essays.js` 共 39 篇公版整篇（逐字拼音、出处与难度标注）。lv1 8 篇（81–159 字）、lv2 8 篇（173–276 字）、lv3 8 篇（320–448 字）、lv4 11 篇（456–624 字）、lv5 4 篇（653–749 字），含《陋室铭》《爱莲说》《桃花源记》《岳阳楼记》《前赤壁赋》《出师表》《滕王阁序》《荷塘月色》等；过长的名篇按语义完整段落节选并标注「（节选）」。
- **入口**：主页「整篇长文」按钮直接跳到第 20 境；第 17–19 境的短句长文入口与玩法保持原样。

## 终极一击

- **蓄势与解锁**：每次**正确**输入 +1 蓄势（逐字母、拼音合成字母、Boss 整句、长文与整篇长文都计入；打错不计）。累计 30 次后槽位满格，HUD 中的终极槽转为金色并显示「Enter 释放」，同时响一次就绪音、角色脚下升起金环、头顶浮出「终」字。
- **释放**：解锁后按 Enter 释放；释放后槽位清零，重新从 0 累计。终极为**每局独立**资源，开局重置，不写入存档。
- **未解锁**：按 Enter 不触发、不消耗，只提示「终极未成 · x / 30 · 正确输入蓄势」，并发出一次轻促提示音；不会打断当前词帖或输入进度。
- **按键分工**：空格 = 重击（需整词完成），Enter = 终极一击。两者彻底分离，不会互相抢输入。
- **长文 / 整篇长文**：词末与句末的重击自动释放，空格此时只提示「长文自动重击」，不会误发；Enter 仍可释放终极一击，蓄势同样来自每个正确字符。Boss 关的整句终结技与终极一击互相独立，可同时存在。
- **输入法**：合成期间（`isComposing` / `keyCode 229` / `imeActive`）所有键先被拦截，因此选字用的回车不会误放终极；上屏后 220ms 内的重击屏蔽只作用于空格。
- **四兵器演出与伤害**（`mul = 1 + 精准度 / 100`，满精准时 ×2）：
  - **弓 · 万箭齐发**：箭矢自角色两侧扇形射出，覆盖全屏；每个敌人 6 支追踪箭，单支 `ATK × 0.75 × mul`；无论敌人数目都会补足 64 支箭雨，保证满屏演出。
  - **剑 · 巨型剑气**：一道横贯全屏的宽幅剑气压带自角色位置向上扫过，路径上的敌人依次结算 `ATK × 5 × mul`，每个敌人只命中一次。
  - **法杖 · 灵压席卷**：以角色为圆心的灵环三层缓出扩散至全屏，每个敌人结算 `ATK × 4.5 × mul`，伴随符文旋转与墨屑。
  - **墨笔 · 水墨鎏金长龙**：金龙自左侧入场，沿正弦轨迹快速往返穿梭两趟（全程约 2.1 秒），龙身与鎏金光晕覆盖范围内的敌人依次受击，每趟结算 `ATK × 2.0 × mul`；两趟结束后龙归墨海，全场墨爆再结算 `ATK × 2.0 × mul`，单敌最高约 6.0 ATK，未被龙身穿过的敌人也至少吃到收尾一击。
- **演出层**：释放瞬间闪白、震屏、角色脚下墨爆并浮出「终极」印。终极特效绘制在投射物之后、墨痕之前，不遮挡 HUD；全部为 Canvas 程序化绘制，无外部资源，`file://` 直接可运行。

## 美术与特效

本轮把程序化 SVG 占位升级为正式美术资源，同时保持原有战斗判定与音画同步不变。

**角色立绘**

- 8 张水墨设色立绘，统一构图、光源与笔触；体态修长，肤色偏暖，服饰以青蓝、玄黑、松绿、赭褐与朱砂为主，避免大面积纯白。
- 立绘一律不画武器，手掌留出可握持的姿态；生成时使用纯绿幕背景，再用脚本抠图：边缘泛洪 + 封闭背景连通域识别 + 去绿边（despill），输出统一为 768×1024 RGBA。
- `assets/skins.js` 负责 `charId + gender → 路径` 映射与掌心锚点，替换立绘只需更新 PNG 与锚点。

**立绘与武器分层**

- `PORTRAIT_ANCHORS` 为每张立绘记录掌心锚点 `{ x, y, dir, scale }`，坐标是 0–1 的立绘归一化坐标；`weaponPose` 给出该武器相对掌心的旋转角。
- 绘制顺序固定为「立绘 PNG → 武器层」：`SKINS.drawWeapon(ctx, weaponId, x, y, scale, rot, dir)` 把武器画在掌心，`scale = 立绘绘制高度 / 1024`，因此皮肤卡、预览和战场按任意分辨率缩放时，武器与人物比例始终一致。
- 皮肤页用 `paintLoadout(canvas, charId, gender, weaponId)` 一次画进同一张 canvas；战场每帧先 `drawImage(立绘)`，再按当前皮肤调用 `drawWeapon`，所以切换弓 / 剑 / 法杖是实时换层，立绘不变、不会残留旧武器。
- 三把武器的握持点都在本地坐标原点，只改变旋转角，换武器时手部位置不跳动。

**战场全屏与背景层次**

- 战斗视图改为 `position: fixed; inset: 0`；canvas 尺寸按 `.monitor-screen` 客户区实时计算，`layoutStage()` 在开战与窗口 resize 时重排人物、敌人槽位与背景，不再固定 1280×800。
- 背景一次性预渲染到离屏 canvas：天幕渐变 → 暖阳与云带 → 三层水墨山峦（脊线浓、山体渐隐）→ 雾带 → 近景地面笔触与草丛 → 墙外树线 → 竹林与飞鸟。山体用 `ridgeWash` 的纵向渐变代替整片实色，避免画面发闷。
- 玩家阵地采用**守城视角**：镜头在城内、略高于墙顶，向城外（画面上方）望去。自上而下依次为「城外地面与来敌 → 垛口（缺口可见城外） → 受光的压顶石 → 背光的女墙内面（砖缝、雨痕、墙脚苔） → 墙影落在的城内步道 → 城台与人物」。外墙面与门洞不再朝向镜头，垛口、压顶与砖缝的受光面统一朝上（朝敌人）。
- 城墙分两层绘制：城外地面、树线、角楼残影留在背景层；**垛口、压顶、女墙内面、步道、城台、守军旗与角楼**画在独立的 `wallCanvas` 上，在敌人之后叠加。因此敌人始终位于墙外，逼近墙根时下半身会被垛口与压顶遮住，形成“隔墙而战”的层次；`TERRITORY_Y` 与破城判定完全不变。
- 人物站在墙内侧的城台上（台面铺向镜头、两侧踏步、台沿「墨关」牌匾与两盏灯），背后是女墙，越过墙顶向外攻击；两端各一座带翘檐的角楼压在墙身上，步道两侧插守军旗。

**武器与投射物**

- 武器与投射物改为 Canvas 预渲染 sprite（2 倍超采样），运行时只做 `drawImage` 加旋转/缩放，避免逐帧重建路径。
  - 弓：笔锋箭镞、纸羽、墨色尾流；蓄力巨箭为长杆、朱砂气、缠绳、三片纸羽与巨笔锋。
  - 剑：轻击为细长弯月剑气；重击为宽幅叠加剑气，墨身、朱砂边、纸白锋三层笔触，两端带飞墨。
  - 法杖：墨球含飞白墨环、纸白高光、朱砂火心与飞沫；重击落雷带天光柱、下坠箭头、「雷」符、双符环与十字准星预警，落雷本体为墨云、锯齿墨身、纸白芯、分叉与落点迸溅。
- 命中与受击：按武器色生成飞溅笔锋粒子，法球命中补一圈墨环，雷击命中生成竖向迸溅；刀光为三重笔触并带两端飞墨；粒子支持笔锋拖尾。

**逻辑与性能**

- 既有规则保持不变：每个正确字符落一次墨点或刀光并对应一次攻击、音效与击键同帧、连击分档升强、打错仅产生轻微墨晕。
- 特效不使用 `shadowBlur` 等昂贵绘制；背景只在开战与 resize 时重绘到离屏 canvas，逐帧只做一次 `drawImage`。无头 Edge（`--disable-gpu`，1440×900）实测第 14 关 10 怪同屏稳定 60 FPS，同屏 6–11 只可正常运行。

## 大破外军（高中英语 3500 词）

专用于英语记忆的独立模式，不复用二十二境的关卡参数。

### 词表与编阵

- 数据文件 `assets/vocab.js`：`window.VOCAB.EN3500` 为 3500 条 `{ w, m, r }`。
  - `w`：小写英文单词（仅 `a–z`、`'`、`-`）。
  - `m`：汉语释义，最多保留 3 个最常用义，以「；」分隔；已清理词性缩写（`adj.` / `n.` / `vt.` 等）与残缺括号。
  - `r`：词频序号，1 为最高频。
- 排序参照近五年常见英文语料的词频（google-10000 词频表）；表中无频次记录的词按原词表顺序排在 3500 之后参与截取。
- 每阵 15 词：`234 阵 = ceil(3500 ÷ 15)`，第 234 阵为最后 5 词。阵卡显示该阵的 `RANK` 区间与首词预览。

### 教学关

- 面板同时显示**汉语释义**与**英文单词**，并显示「连对 x / 3」与「第 n / 15 词」。
- 完整输入该英文单词一次记为 1 次连对；**连续输对 3 次**才进入下一个词，满 15 词过关。
- 输错一次：连对清零、当前词进度归零，需重新连对 3 次。
- 敌人是固定在战场上的**木桩靶**：不移动、不进攻、不可被击杀，仅用于承受重击演出。
- **无时间限制**，可慢慢记词。

### 练习关

- 必须**完成同阵教学关**后解锁；未解锁时按钮置灰。
- 只显示汉语释义，**隐藏英文答案**；每输入一个正确字母，向最近敌人发射一次普通攻击。
- 面板下方只显示**已经输入的正确字母**（不会提前露出剩余字母），打错字母不推进并断连击。
- 满 15 词即过关；敌人会正常进攻，生命归零判负，但不限时。

### 存档与兼容

- 进度写入 `mozhan.save.v1` 的 `army.teach` / `army.practice`，键名为 `a0`、`a1`…（普通阵）或 `c0`、`c1`…（自定义阵）。
- 旧存档无需迁移：加载时自动补齐 `army`、`customWords`、`customLevels`、`customNextId`、`endless` 等字段，原有 22 境记录、皮肤、熟练度、墨玉、处方与速字模式保持不变。

## 自定义词库与自定义词战

### 录入词条

- 输入英文与汉语释义，点击「录入词条」即生成一条词条，自动编号（`#1` 起递增，删除后编号不复用）。

- 列表逐条显示编号、英文与释义。

### 编排关卡

- 在「编排关卡」输入 **15 个词条编号**（空格或逗号分隔），点击「保存关卡」生成「第 N 阵」。

- 每阵同样分教学关与练习关，规则与普通阵完全一致。

```js
// localStorage: mozhan.save.v1
save.army = { teach: { a0: true, c0: false }, practice: { a0: true } };
save.customWords = [{ id: 1, w: 'lantern', m: '灯笼' }];
```

战役每局结束会向 `history` 追加 `{t,lv,acc,cpm,wpm,combo,time}`，最多保留 24 条；旧存档自动补空数组。

## 局域网联机

- 入口：首页「联机」组。桌面版自带房间服务；浏览器 `file://` 单机版无服务，大厅会提示改用桌面版。
- 连接：一方「创建房间」，另一方在房间列表选择加入；桌面版通过 UDP 组播（`239.255.42.99:8790`）自动发现同网段房间，可手动刷新。
- 内容：可选 英语 · 汉译英 / 英语 · 直接显示 / 汉语文章；由房主生成序列，服务端校验后原样下发给双方，保证同题。
- 战斗：双方分列战场左右；每正确输入一个字母发一击，整词完成按空格发三倍重击。自己的攻击既打对手，也能拦截对手来袭攻击——一发攻击需累计承受不低于自身伤害的伤害才会被清除（累计值 `>=` 自身伤害即销毁）。
- 数值：生命 180；单发伤害由客户端给出（`5 × (1 + acc/100)`，整词 ×3），服务端乘以 0.86–1.14 浮动并限制在 1–70；对局上限 150 秒，超时按剩余生命判定。
- 生命周期：对手退出或掉线判胜并回到房间；房间空闲 10 分钟回收；连接断开自动重试并提示，不会卡在战场。

## 已知限制

- 立绘为静态图片，不含眨眼或呼吸动画；如需动态立绘，可在此基础上扩展逐帧或骨骼动画。
- 联机必须通过桌面版（内嵌房间服务）建立连接；`file://` 页面之间无法互连。两端需在同一局域网，且路由器未隔离组播/客户端；若自动发现失效，可由房主告知加入方地址与端口。
- 存档损坏（JSON 解析失败）时会自动重置为新档并在首页提示；旧进度无法恢复。清除浏览器数据同样会清空记录。
- 词库或语料文件缺失时，对应入口会给出「词库为空 / 暂无可用语料」提示；核心脚本缺失时顶部会出现资源加载失败提示条。
- 中文判定依赖浏览器输入法事件；极少数输入法若不派发 `compositionupdate`，将走 0.5 秒兜底路径。
- 速字模式的输入法路径以实际上屏汉字为准，逐字与整词提交均可；若输入法只回传汉字而不派发 `compositionupdate`，仍能按上屏汉字完成判定，但不会累计对应的拼音精准度。
- 长文模式中，中文词的划分固定为「每 2 个汉字一词，遇逗号、顿号、分号、冒号提前收词」，因此四字成语按 2+2 两次重击结算；英文按空格与标点切词，撇号不切词。
- 整篇模式的「整篇长文库」与短句长文库（`longtexts.js`）互相独立；第 20–22 境只从 `essays.js` 取整篇，第 17–19 境只从 `longtexts.js` 取短句批次，两个入口不会串库。
- Boss 攻防关的标点按半角键位判定（`，`→`,` 等）；若输入法把逗号用作翻页/选字快捷键，可直接切换英文标点或用输入法上屏全角标点，两种方式都判定为正确。
- Boss 攻防关的「本源」推进与墨弹伤害是固定的时间压力，不随玩家生命值缩放；生命归零或本源推进到第 6 阶都会判负。
- Enter 专用于终极一击；极少数不派发合成事件的输入法若用回车提交候选，可能触发「终极未成」提示，改用空格或数字选字即可，不影响判定。
- 游戏为纯前端静态页，无排行榜与云端存档，记录与速字开关仅保存在本机浏览器。
- 大破外军 3500 词按 15 词/阵切分，末阵只有 5 词；词频表未收录的词按原词表顺序排在末尾参与截取。
- 大破外军的教学/练习与无限模式不计入二十二境最佳记录、不发放墨玉、不更新训练处方；这些主线奖励仍只在战役模式结算。
- 自定义词战的进度按关卡索引保存，删除中间关卡后，其后关卡的进度会与新的索引错位；建议只删除末尾关卡。
