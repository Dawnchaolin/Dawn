# 墨战 · 键影（Mozhan Keyblade）

水墨风打字闯关游戏：以键盘为锋，键入词句斩尽来敌。纯静态页面可双击运行，另有 Windows 桌面版承载局域网双人对战。

## 快速开始

- **单机（浏览器）**：双击 `outputs/index.html` 即可，无需安装、无需起服务。
- **单机（本地服务）**：`cd outputs && python -m http.server 8777`，访问 `http://127.0.0.1:8777/`。
- **桌面版（Windows）**：构建后双击 `release/MozhanKeyblade-win32-x64/MozhanKeyblade.exe`。应用会自动拉起内嵌房间服务，无需手动配地址。

```powershell
cd outputs
npm install
npm run dist:win
```

产物为便携目录版，整个目录复制即可运行。若打包机离线，可追加 `--electron-zip-dir=<本机 electron zip 缓存目录>`。

## 联机说明

- 双方需使用 **桌面版**（浏览器 `file://` 页面之间无法建立连接）。
- 两端处于同一局域网；桌面版通过 UDP 组播自动发现房间，也可在列表里手动刷新后选择加入。
- 一方「创建房间」，另一方「加入」；对战内容由房主选择（英语汉译英 / 英语直接显示 / 汉语文章），双方拿到完全相同的序列。
- 输入正确即攻击，自己的攻击既能打对手也能拦截来袭攻击；生命 180，对局上限 150 秒，超时按剩余生命判定。
- 掉线、对手退出、超时均会判胜并回到房间，连接断开自动重试。

## 玩法一览

- **闯关**：二十二境，从基准键位到整篇长卷，限时斩满目标即过关。
- **大破外军**：高中英语 3500 词按词频编阵，看汉语回忆英文拼写，含教学关与练习关。
- **长文 / 整篇**：公版长文逐字输入，句读自动重击；整篇模式百字至八百字整块翻页。
- **无限模式**：英语 / 长句 / 文章自由组合，无终点连战。
- **联机对战**：局域网同题对坐，攻守相消。
- **训练报告**：跨局汇总 CPM / WPM、综合精准、五组键位熟练度、易错键热力图与近期趋势。

操作：照着词帖输入；整词完成后按 `空格` 重击（三倍伤害）；蓄满 30 次后按 `Enter` 释放终极。首次打开有三步上手浮卡，可跳过。

## 目录结构

```
typing-battle/
├─ .gitignore
├─ README.md                 本文件（仓库入口）
├─ release/                  Windows 打包产物（不入库）
└─ outputs/
   ├─ index.html             单机入口（双击即玩）

   ├─ server/room-server.js  静态托管 + WebSocket 房间 + 组播发现

   ├─ README.md              完整玩法、规则、数据结构与联机细节

```

## 数据与存档

- 进度保存在浏览器 `localStorage['mozhan.save.v1']`，桌面版与浏览器各自独立。
- 存档损坏会自动重置并提示；清除浏览器数据会同时清空训练记录。
- 全部素材随目录离线加载，运行时不发起网络请求（联机仅访问局域网内房间服务）。

完整规则、关卡参数、数据结构与开发展开说明见 [outputs/README.md](outputs/README.md)。
